# Yearly calendar

Put these in your phone calendar with a reminder a week before. The Australian financial year runs from 1 July to 30 June; royalty periods follow the calendar half years in the author agreement.

| When | What | Where to find it |
| --- | --- | --- |
| **Every publication** | Legal deposit within one month of publication (National edeposit for ebooks and print; State Library of NSW copy for print) | Setup checklist 4 |
| | Update the title details at Thorpe-Bowker for each ISBN | myidentifiers.com.au |
| | Register the title for lending rights and with Copyright Agency | Setup checklist 4 |
| | File signed contracts and permissions with the book | Agreements |
| **January** | Collect platform payout reports for July to December | Money tracker |
| **By end of February** | Send royalty statements and payments for July to December (within 60 days of 31 December) | Money tracker, email templates |
| **By 31 March** | Donate for the previous calendar year and publish the yearly donation statement | Donation policy |
| | Lending rights: claim new titles (check the closing date each year) | Office for the Arts |
| **May** | Review the spec files in Borderless Studio (Settings, Platform rules); check prices still match each store's rules | Borderless Studio |
| **30 June** | End of financial year: download all platform reports, reconcile the bank account | Money tracker |
| **July** | Collect payout reports for January to June | Money tracker |
| **By end of August** | Send royalty statements and payments for January to June | Money tracker |
| **By 31 October** | Lodge your tax return (later if you use a registered tax agent) | ato.gov.au |
| **November** | Review the spec files again; review prices | Borderless Studio |
| **Business name renewal** | Every one or three years, from the registration date | ASIC |
| **ABN and contact details** | Update within 28 days of any change of address | abr.gov.au |
| **GST (only if registered)** | Business activity statements, usually quarterly | ato.gov.au |
